## 1. 逐项落点

### F1 调试面板（P0）

- `settingsPanel.ts`
  - `DebugEventItem`：`actionId: number` → `key: string` + `name: string`（+ `actionId?` 仅显示）；
  - `onTriggerEvent?: (key: string) => boolean`；
  - chip：`text = name`、`hint = "事件键 ｜ #actionId ｜ 动画:xxx"`、`id = 'wb-debug-ev-' + domKey(key)`。
- `index.ts`
  - `events: activeDialogues.map(d => ({ key: eventKeyOf(d), name: d.displayName || d.label || eventKeyOf(d), actionId: d.actionId, animation: d.animation }))`；
  - `onTriggerEvent(key)` → `findByEventKey(phasedDialogues, key)` → `touchController.trigger(entry, 'touch')`。

### F2 常驻序列闸门

```ts
// index.ts：入参是归一后的 EventKey（字符串），表里 actionId 是 number
isActionAllowed: (id) => {
  const key = normalizeEventKey(id);
  return !!key && phasedDialogues.some((d) => eventKeyOf(d) === key);
}
```

### F3/F4 档案

- `ArchiveState` 新增三个字段：`enumerated`（已逐条列出的键账本）、`disabledCount`、`gatedOut`；
- `resolveState`：`active` → `playable`（`enabled !== false`）→ `phased`（事件族闸门）；池只从 `playable` 建；
- `makeRow`：把键写进账本；角标人名改 `displayName || shortLabel(label)`（否则去掉重复段后自定义事件只剩 `#custom:xxx`）；
- ⑥ 自定义段：只列"账本里没有的"，并按原因标注 `已被「事件开关」关闭` / `所属事件族未勾选` / `不可达`；
- `buildNotes`：`disabledCount > 0` 时输出「另有 N 条被关闭」+ 指路到面板第 5 页。

### F5 序列项往返

| 形状 | 编码（`stringifyItem`） | 解码（`parseSequenceItem`） |
|---|---|---|
| `'chat'` | `'chat'` | `'chat'` |
| `{ key: 'custom:x' }` | `'@custom:x'` | `{ key: 'custom:x' }` |
| `{ actionId: 64005 }` | `'#64005'` | `{ actionId: 64005 }` |
| `{ animation: 'chat' }` | `'chat'` | `'chat'`（语义等价，`resolveSequence` 同样处理） |

面板「常驻动作序列」页额外提示"另有 N 项按事件键/动作 ID 引用，本页不展示、保存时原样保留"。

### F6 chip 反馈

`makeChipGroup` 回调：返回值 `true` ⇒ 白闪 3s；`false` → **红闪 3s** + `data-wb-last="fail"`（回归断言用）。
`onTriggerEvent` 被事件族闸门挡下时就是这条路径 —— 用户在面板上能直接看出"没播"。
