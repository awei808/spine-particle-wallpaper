## 0. 一句话

事件表只有一个文件、一个来源：`assets/events.jsonc`（带注释）。
设置面板那一页只剩**每条一个开关**；增删改字段一律编辑该文件。

## 1. 为什么改

### 1.1 现状链路（改造前）

```
assets/config.json
  └ subtitle.dialogues[]            ← 内置事件
        ↓ readEventOverrides()      ← localStorage['wb.swe.events.v1'] {added[], disabled[]}
        ↓ mergeEventOverrides()      src/eventOverrides.ts
        ↓ normalizeEventTable()      src/eventModel.ts（唯一归一入口）
        ↓ eventTable                 index.ts
        ↓ 投影 / 族闸门 / 池 / 档案 / 面板
```

`archive.ts` 的 `resolveState()` 还**自己**从 `config` 再归一一次（第二份表）——
这是本次顺手收掉的重复真相。

### 1.2 面板当作者入口，走不通（不是没做完）

| 面板能做的 | 用户真正要的 |
|---|---|
| 念白/语音**只能从现有条目继承**（零键盘，PLAN §7） | 新台词 + 新语音文件 |
| 条件只有 5 个模板 | 任意 `when` AST |
| 不能写 `phase` / `phaseAnimations` | 指定事件族 |
| 只暴露 `priority` + `quota.day` | `weight` / `group` / `cooldownMs` / `interrupt` / `variants` |
| 删除只对本机 `added` 生效 | 删任意一条 |
| 写 localStorage（换机 / 换工程 / 工坊更新后消失） | 内容属于**工程**，能提交、能 diff、能审阅 |

已出的三个 bug（`custom:` 前缀误判、`weight:0` 占档、池空兜底失效）全部来自同一个根因：
**两处都能写事件**。文件化之后这类 bug 不可能再出现——面板只写一个布尔值。

### 1.3 为什么推翻「不新建 events.json」

那句话的前提是"面板是作者入口"。前提消失后：`config.json` 是**构建产物**
（被 `21_生成配置.py` / `17_` / `49_` 重写），注释必被冲掉，装不下 100 行说明。
「唯一真相」的纪律**不变**：仍然只有一张事件表，只是它的**文件**换了。

## 2. 目标 / 不做

**目标**

1. 事件（内置 + 自定义）只存在 `assets/events.jsonc`，带注释。
2. 面板页「事件开关」：**只能开 / 关**某条事件。
3. 增 / 删 / 改字段 = 编辑该文件；面板给出明确指引。
4. 顺手收掉 `archive.ts` 的第二份归一（第二真相）。

**不做**

| 不做 | 理由 |
|---|---|
| 兼容 `localStorage['wb.swe.events.v1']` | 从未发布，直接换键，无迁移代码 |
| `config.subtitle.dialogues` 兜底 | 单一来源；缺文件就是 0 条 + 红字（见 §4） |
| 热重载 | 池 / 漏斗 / 校验都是开机一次性构造 |
| 文件里定义骨架动画 / 粒子系统 | 只**引用**已有名字（PLAN §12） |
| 文件里写 `eventFamilies` / `phases` / `actionPhase` | 环境参数，留 config（PLAN §1 边界表） |
| 表达式 / JS 片段 / `$ref` | 不可审计、不可离线校验 |
| 面板内任何文本输入 | WE 的 CEF 无可靠输入法焦点（PLAN §7） |

## 3. 文件设计

### 3.1 位置与命名

```
<工程>/assets/events.jsonc
```

- 与 `config.json` 同目录；`webpack.common.js` 的 `CopyPlugin` **整目录拷 `public/`**
  ⇒ `public/assets/events.jsonc` 自动进 `dist/`，构建链零改动。
- 用 `.jsonc` 不用 `.json`：`.json` 里写注释编辑器会标红；比 `.js` 好在数据不是代码
  （离线 CLI 解析同一份字节，不 `require`、不污染全局）。

### 3.2 顶层结构

```jsonc
{
  "schema": 1,
  "events": [ /* DialogueEntry[] */ ]
}
```

| 键 | 必填 | 说明 |
|---|---|---|
| `schema` | | 缺省按 `1`；`>1` ⇒ 一条 warn（不拦），提醒"引擎比文件旧" |
| `events` | ✅ | 数组；不是数组 ⇒ 整份作废并报错（**不静默当空**） |

### 3.3 条目字段（= `DialogueEntry`，语义以 `src/config.type.ts` 为准）

| 字段 | 什么时候用 |
|---|---|
| `id` | `"custom:xxx"` / `"game:64005"`；不写则由 `actionId` 派生 |
| `actionId` | 仅内置事件：与游戏表对齐、档案溯源 |
| `label` / `displayName` | 面板与档案显示名（`displayName` 优先） |
| `note` | 一句话，进档案细则 |
| `enabled` | 缺省 `true`；写 `false` = 作者默认关闭（用户仍可打开） |
| `on` | `touch` / `standby` / `resume` 或数组；缺省 `["standby"]` |
| `kind` | `chat` / `greet` / `touch`；缺省按 `on[0]` 推 |
| `when` | `time{start,end}` / `calendar{month,day}` / `ctx{zone,idleMs}` / `and/or/not` |
| `phase` | 事件族 id；自定义事件**建议不写**（落缺省族 = 不换名、恒可见） |
| `phaseAnimations` | 键 = 族 id，值 = 该族下的动画名 |
| `animation` | spine 动画名；不写 ⇒ 纯台词事件 |
| `particles` | `config.meshes[].name`（`type:'particle'` 那批）；不写 ⇒ 回落 `actionEffects` |
| `variants` | 整包随机（动作 + 台词 + 语音同包） |
| `text` / `textTime` / `voice` | 念白 / 停顿时长 / 语音文件名 |
| `pick` | `{priority, weight, group, cooldownMs, quota, interrupt}`；**`weight:0` = 只手动** |

### 3.4 注释解析口径

| 项 | 支持 | 备注 |
|---|---|---|
| `// 行注释` / `/* 块注释 */` | ✅ | 块注释可跨行 |
| 尾逗号 `,]` `,}` | ✅ | JSONC 惯例 |
| BOM / CRLF | ✅ | 生成器可能写 CRLF |
| 字符串里的 `//`（`"https://…"`） | **不受影响** | 必须状态机，不能用正则先剁 |

**实现要点：等长替换**。注释字符替换成**空格**（保留 `\n` 与所有偏移），
`JSON.parse` 的 `position` 能 1:1 换算出**原始文件的行:列** ⇒ 用户改错一个逗号，
看到的是「第 87 行 第 14 列」，不是"意外的 token"。

### 3.5 文件头注释（交付物的一部分）

1. **这是什么**：事件表唯一来源；`config.json` 只管环境参数。
2. **改完怎么生效**：保存 → WE 里重载壁纸。
3. **字段速查**：§3.3 的浓缩版 + 指向 `src/config.type.ts`。
4. **三条完整示例**：内置型（时段问候 + 语音）/ 纯手动型（`weight:0`）/ 节日型（`calendar` + `quota`）。
5. **优先级五档**（80 用户操作 / 50 节日 / 20 时段问候 / 10 日常 / 0 默认）。
6. **和面板的关系**：面板只能开关；文件写 `enabled:false` = 默认关，用户仍可打开。
7. **校验**：`npx ts-node --transpile-only scripts/validateEvents.ts <assets目录>`。

## 4. 事件源：只有一个

| `assets/events.jsonc` | 结果 |
|---|---|
| 存在且可解析 | **唯一来源**，`config.subtitle.dialogues` 一律忽略 |
| 不存在 / 404 | **0 条** + `console.error` + 面板红字 |
| 存在但解析失败 | **0 条** + `console.error`（含行:列）+ 面板红字 |

没有 fallback，没有"两个都能跑"的状态：

- 少了文件就**立刻看得见**（面板红字 + 控制台），而不是"事件变少了但还能播"；
- 迁移期只需要保证"部署 bundle 时把 `events.jsonc` 一起放进去"（§7 的部署红线）。

### 5.1 localStorage 键

```ts
// src/eventOverrides.ts
export const EVENT_STATE_KEY = 'wb.events.state.v1';
type EventState = { schema: 1; enabled: Record<EventKey, boolean> };
```

- **只记录用户点过的键**（点击即写显式值，不做"与文件缺省比较"）⇒ 简单、无隐式语义；
- `enabled` 为空的 map = 全部按文件缺省（「恢复默认」就是清空它）；
- 旧键 `wb.swe.events.v1` **不读、不删**（从未发布，留着也无副作用）。

## 6. 面板新形态

### 6.1 标签与锚点

- 标签「自定义事件」→ **「事件开关」**；`id` 仍 `events`（`wb-tab-btn-events` / `wb-tab-events` 不动）。

### 6.2 页面内容（只有三块）

```
┌ 事件内容：assets/events.jsonc —— 支持注释；增删事件 / 改字段请编辑此文件，改完重载壁纸
│ 来源：events.jsonc（12 条）           ← 或红字：events.jsonc 解析失败：第 8 行 第 12 列 …
│ 共 12 条 · 已开启 11 条
├ [✓] 晴日上午问候 · 回到壁纸 · 时段 05–11 · greet · game:64001
├ [ ] 情人节问候   · 回到壁纸 · 2月14日   · greet · custom:valentine-greet
└ …
   [恢复默认（全部按文件设定）]                     [保存并应用]
```

- 顶部三行：**文件指引**（需求里的"告知用户"）、**来源/错误**、**统计**。
- 每行沿用现有一行式 `名称 · 通道 · 条件 · 动画 · id`，**没有删除按钮**。
- 「恢复默认」= 清空 `EventState`；保存仍与设置项同一次（落盘 → 重载）。
- 不做滚动（WE 不转发滚轮）；12 / 13 条一行 24 px 应放得下，**验收时实测**，超了加分页。

### 6.3 开关语义

| 文件 | 用户点 | 落盘 |
|---|---|---|
| 未写 / `true` | 关 | `enabled[key]=false` |
| 未写 / `true` | 开 | `enabled[key]=true`（等价，但保持"点过就写"的一致性） |
| `enabled:false` | 开 | `enabled[key]=true` |
| `enabled:false` | 关 | `enabled[key]=false` |

> 为什么允许"写了 true 却与缺省相同"：**面板不需要知道文件缺省**（否则要传两份数据）。
> 一个显式布尔 map 是最小接口；存储只随"用户点过的条数"增长。

5. 把文件改坏（删一个逗号）⇒ 面板红字 + 0 行 + 控制台报行列；
6. 删掉整个文件 ⇒ 面板红字"未找到"，事件 0 条。

`fetch('./assets/events.jsonc')` 在 `file://` 下的可行性——与 `config.json` 同一条路，
